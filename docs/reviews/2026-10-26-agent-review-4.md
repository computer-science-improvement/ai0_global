# Agent review 4 — dev stage 10-21 … 10-26

Fourth offline review of the agents' work (review 3: `2026-10-22-agent-review-3.md`).

**Source.** `scripts/export-agent-history.sh 6` on the dev stage at `64df1c89`. That commit contains specs 060–066 and the dependency patch.

**Size.** 338 runs, 2691 steps, 80 slots, 27 published posts (23 from slots, 4 from chat drafts), 3 owner chats (13 messages), 63 Inbox notes, 61 owner-bot cards, and the container log from 10-22 18:49 to 10-26 20:00.

**Method.** Four analysts covered the critic, material and planning, the owner's loop, and runtime and cost. One skeptic per area re-checked every finding in the data and the code. Corrections are folded in below. The headline mechanisms were re-checked in code, and the breaker was replayed over the real slots.

## Verdict

Specs 060–066 shipped and run without errors, but **output fell**: 23 slot posts in 6 days, against 44 in 7 days in review 3.

- **Skip rate.** 57 of 80 slots were skipped (71%, review 3: 54%).
- **Wasted spend.** After the deploy, 74% of executor and critic spend went to slots that produced no post. Cost per published post is $0.65.
- **Total spend is fine.** $1.6–3.9 a day ($1.96 a day after 10-22), under the $3 target, because the critic left Opus.

Three causes explain most of the loss.

1. **The critic kills posts it cannot check.** It does not see what the author read. Since 065, a large page reaches the critic as its first 3,000 chars only, and `read_doc` / `find_in_doc` output never reaches it at all. The verdict code then turns the model's own "revise" into a kill and bans the source. 31 of 57 skips start at the critic. About 10–15 of the 23 post-deploy critic kills were not justified, though several of those drafts also had small real defects.
2. **Dead series are still planned and run every day.** The 060 breaker never fired: `series_pauses` is empty. Its free-text classifier puts one root cause into different classes, so the streak resets. The plan validator forces 2 posts a day even when the planner honestly says there is no material. Migration 083 makes the text-less PromptHero rows count as "postable" (4764 unposted), which hides the truth from the planner, the pre-flight and the breaker.
3. **The owner's source change never reached the pipeline.** On 10-22 the owner moved @ai0_prompts_dev to awesome-nanobanana-pro and @ai_global to prompts.chat. The composer wrote skills, not imports (`import_list`: 0 calls). The planner does not read those skills, so 9 more Prompt slots were planned on PromptHero rows: 8 were skipped and 1 posted off-instruction.

Two of these are our own regressions:

- 065 made the critic's source smaller and did not connect the document store to the critic.
- 060 was tested with one fixed phrasing of a skip.

## P3

- **Attribution.** To meet the "no author/link" request, the composer posted a CC BY 4.0 prompt as `origin=original` (post 1756). After the import, use `origin=library` with `library_ref`: nothing is rendered, provenance and licence stay in the ledger. Lint and `edit_my_skill` refuse `origin=original` for text taken from a fetched doc or library row.
- **062 claim-guard retry.** A true past-turn statement (a skill applied by card earlier in the same chat) was flagged. The retry replaced a useful answer with a meta-apology. Count applied cards and earlier tool calls of the chat as backing. The re-prompt asks for a fresh answer to the owner's last message.
- **story_repeat false positive.** On 10-26 11:00 (@ai0_global) two brand names given as examples made an explainer «the same story» as one from 10-15.
- **Plan-time checks.** 3 of the 5 pre-flight skips (stale, already used, carousel without `SUPABASE_CAROUSEL_BUCKET`) could have been refused at `submit_plan` for ~$0.001. Run `formatAvailable` and the used/stale checks in plan validation, and drop carousel while slide hosting is missing.
- **Fixed overhead.** The executor's first call is 26.6k tokens: 11 offered tools are never called after the deploy, and `read_doc` / `find_in_doc` added ~0.8k. Drop the unused tools through the 054 per-agent loadout, but keep `extract_images` for @ai0_prompts_dev. Manager runs write 185k cache tokens and read none: pass `cache: false` at `manager-runner.ts:230`.
- **Deploy restarts a half-booted container** (`deploy-develop.yml:121` `docker compose restart automation` right after `up -d`). Nest re-raises SIGTERM while booting, node as PID 1 ignores it, and Docker kills it after 10 s. Same as before the upgrade, so not a regression. Delete line 121 and add `init: true` to the automation service.
- **Meta.** Two Threads accounts have been expired since 08-17/18 and produce a daily card. `page_views_total` on facebook/1391025657426668 returns 400 on all 98 hourly ticks, and the 064 back-off does not match it. Back off any metric after 3 consecutive 400s, and log the Graph code and message.

- **061.** Source anchors work (`zakon …/print#п.1.3` on 10-25). The pre-flight made 5 correct $0 skips with no false positives. Host strikes escalate as specified.
