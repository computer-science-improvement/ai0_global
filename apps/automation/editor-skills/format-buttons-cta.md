# Кнопки і CTA

`cta: {url, label}` → одна кнопка під постом. `buttons` → додаткові ряди (до 4 рядів по 1–3 кнопки).

## Коли ставити
- Є одна чітка дія для читача: «Читати повністю», «Рецепт на Telegraph», «Забрати гру безкоштовно», «Трейлер».
- Пост — анонс, а суть за посиланням.
Якщо дії немає — кнопку не ставимо. Кнопка «Підписатися» на свій же канал — зайва.

## Тексти
- ≤ 40 символів, дієслово + обʼєкт: «Відкрити рецепт», «Дивитися трейлер».
- Без капслоку і без «ТИСНИ!!!».
- Емодзі в кнопці — максимум одне на початку, якщо в каналі дозволені емодзі.

## Обмеження
- Альбоми кнопок не підтримують.
- URL лише https/http і лише справжні (не вигадані).
- Реклама й спонсорські кнопки **не** ставляться агентом — їх додає система для оплачених замовлень.
