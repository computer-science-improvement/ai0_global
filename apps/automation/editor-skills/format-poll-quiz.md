# Опитування (poll) і вікторина (quiz)

Залучення в Telegram найдешевше отримати через голосування. Але лише якщо питання цікаве.

## poll — думка аудиторії
- Питання про досвід/вибір читача: «Що готуєте на вечерю в будні?»
- 2–6 варіантів (максимум 10), короткі (≤100 символів), взаємовиключні, з варіантом «Інше/не знаю», якщо доречно.
- Без правильної відповіді (correct_index не ставимо).

## quiz — перевір себе
- Питання з однією точно правильною відповіддю, яку ти **перевірив** (див. `fact-check`).
- `correct_index` — індекс правильного варіанту з 0.
- `explanation` ≤ 200 символів — коротко чому, з цифрою/фактом. Показується після відповіді.
- Неправильні варіанти правдоподібні, не жартівливі.
- Для ПДР/правил — тільки з першоджерела (бібліотека `pdr_questions`).

## Вступний пост і зображення
- Якщо `body` не порожній — спершу вийде пост (з хештегами), потім опитування. Використовуй, коли треба контекст: «Вчора NASA оголосило… Як думаєте, коли люди…?». Без контексту — лише опитування.
- **Зображення:** опитування в Telegram не може містити картинку, тому `media[0]` стає **фото перед опитуванням** (з `body` як підписом). Якщо в записі бібліотеки є `image` (у ПДР — картинка дорожньої ситуації), **обовʼязково** додай її в `media` — без неї питання про ситуацію незрозуміле. Тоді в `body` — коротко: «Білет 17, питання 4. Дивіться на схему 👇».
- Максимум одне зображення.

## Технічні межі
question ≤ 300, options 2–10 по ≤100, варіанти не повторюються. Розмітка в питанні/варіантах ігнорується (plain text).

## Приклад quiz з ПДР (зображення ситуації з бібліотеки)
```json
{"format":"quiz","title":"ПДР: рух крайньою лівою смугою","origin":"library","library_ref":"library://pdr_questions/1234",
 "body":[{"type":"p","text":"Білет 17, питання 4. Подивіться на ситуацію 👇"}],
 "media":[{"url":"https://…/ticket17_q4.jpg","alt":"Схема перехрестя"}],
 "poll":{"question":"Чи може цей транспортний засіб рухатися крайньою лівою смугою?","options":["Може завжди","Не може","Може — для повороту ліворуч або розвороту"],
         "correct_index":2,"explanation":"<пояснення з поля explanation цього запису бібліотеки, ≤ 200 символів>"}}
```

## Приклад quiz
```json
{"format":"quiz","title":"Вікторина: найбільша планета","origin":"original",
 "poll":{"question":"Яка планета Сонячної системи найбільша?","options":["Сатурн","Юпітер","Нептун","Земля"],
         "correct_index":1,"explanation":"Юпітер у 11 разів ширший за Землю і важчий за всі інші планети разом."}}
```
