# TikTok (фото-режим)

## Формат `tt_photo`
- 4–8 слайдів (максимум 35). Кожен — **великий короткий текст** (до ~15 слів) поверх фону: це гортають великим пальцем за секунду.
- Слайд 1 — гачок, що змушує гортати: «5 речей, які…», «Ти робиш це неправильно…», питання.
- Останній слайд — висновок + «підпишись, щоб не пропустити».
- `title` (заголовок поста) — до 90 символів, без хештегів.

## Опис і хештеги
- 1–3 речення + 3–5 хештегів (тема + 1–2 ширші). Посилання не клікабельні — не вставляй URL.
- Мова жива, коротка, можна з легким гумором, без кліше.

## Обмеження
- Поки застосунок не пройшов аудит TikTok, пости через API **видно лише автору** (SELF_ONLY): не рахуй їх як охоплення.
- Зображення мають бути на верифікованому домені (хостинг слайдів) — використовуй `slides`, а не чужі URL.
- Відео (`tt_video`) поки недоступне (потрібен відеоконвеєр, спека 016): не плануй його.
