# Зображення і їх розташування

## Формати з одним зображенням
- `photo` — класичне фото з підписом. Підпис ≤ 1024 видимих символів. Якщо текст довший — рендерер **сам** перетворить пост на текст із великим превʼю картинки (до 4096 символів). Обрізати текст не треба.
- `text` + `media[0]` — текст з великим превʼю картинки. Добре для лонгрідів із «обкладинкою».

## placement
- `above` (за замовчуванням) — картинка зверху, текст під нею. Візуальні канали (космос, рецепти, фото дня).
- `below` — спочатку текст, картинка під ним. Коли головне — думка/новина, а картинка ілюстрація; або щоб пост у стрічці «читався» з першого рядка.
Тримай один стиль у рубриці: якщо серія «Фото дня» завжди `above`, не міняй без причини.

## Яку картинку брати
1. З першоджерела (`extract_images` по URL статті, `og_image`) або з бібліотеки (`image_url`).
2. Тільки https, без svg/gif, без водяних знаків чужих каналів.
3. Не використовуй картинку, яка не стосується тексту (стокова «людина за ноутбуком» до новини про закон — погано).
4. Немає доречної картинки → формат `text` без media. Це краще за випадкову.

## alt / credit
`alt` — що на зображенні (для аналітики). `credit` — автор/джерело фото, якщо відомий («NASA/JWST»).
