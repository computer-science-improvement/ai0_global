# Альбом (слайдер)

`format: "album"` → Telegram media group, читач гортає фото.

## Коли доречно
- Покроковий рецепт (етапи приготування), «до/після».
- Добірка: 3–5 фільмів тижня, кілька знімків однієї події, інфографіка частинами.
- Коли кожне фото несе окрему інформацію. Якщо фото — варіації одного й того самого, бери одне (`photo`).

## Правила
1. 2–10 зображень, усі https і з одного легітимного джерела/джерел, що цитуються.
2. Порядок = сюжет: перше фото — найсильніше (воно ж обкладинка в стрічці).
3. Підпис (весь текст поста) показується **лише під першим фото**, ≤ 1024 символів. Пиши коротше, ніж для photo.
4. **Кнопки не підтримуються** — ніяких `cta`/`buttons`, а якщо в картці `link_style: button`, обирай інший формат або постав посилання в тексті.
5. Нумеруй у тексті, якщо порядок важливий: «1 — тісто, 2 — начинка…».

## Приклад
```json
{"format":"album","title":"Добірка: 4 знімки затемнення",
 "media":[{"url":"https://…/1.jpg","alt":"початок"},{"url":"https://…/2.jpg"},{"url":"https://…/3.jpg"},{"url":"https://…/4.jpg"}],
 "body":[{"type":"lead","text":"Затемнення над Карпатами — 4 кадри"},{"type":"p","text":"Від першого дотику до повної фази минуло 72 хвилини."}],
 "hashtags":["космос","фото"],"origin":"external","source":{"url":"https://…","label":"ESA"}}
```
