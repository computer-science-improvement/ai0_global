# Карусель (carousel)

`format: "carousel"` → ти пишеш **текст слайдів**, код рендерить їх у картинки 1080×1350 (заголовок, текст, лічильник «1/5» поверх фонового фото або темного тла) і публікує в Telegram альбомом. Ті самі слайди можна дублювати в Instagram/Facebook/Threads як карусель — рішення по кожному ресурсу (дублювати, адаптувати, унікальний пост чи пропустити) див. скіл `resource-decisions`.

## Коли доречно
- Покрокові інструкції: рецепт етапами, «як налаштувати», чекліст.
- Розбір по пунктах: «5 фактів про…», «3 помилки новачків», порівняння «до/після».
- Коли читач має **зберегти** пост і повернутися. Для однієї думки краще `photo` або `text`; для чужих знімків — `album`.

## Правила
1. `slides`: 2–10 об’єктів `{title, text, image?}`. `media` залиш порожнім.
2. `title` ≤ 80 символів, коротко й конкретно («Крок 2. Тісто»). `text` ≤ 400, але краще 1–3 речення: на картинці великий шрифт.
3. Текст слайдів — **звичайний текст**, без `**`, посилань і емодзі-гірлянд. Мова — українська.
4. `image` — https-зображення з джерела, яке цитуєш (або без фону). Фон затемнюється, тож підходять і яскраві фото.
5. Перший слайд — обкладинка: найсильніший гачок. Останній — висновок або підсумок.
6. `body` — підпис під першим слайдом (≤ 1024): 1–2 речення, навіщо гортати, джерело й хештеги додає код.
7. **Кнопки не підтримуються** (як в альбомі): без `cta`/`buttons`; якщо в картці `link_style: button`, обери інший формат.
8. У режимі апруву слайди малюються одразу: власник бачить саме ті картинки, що підуть у канал. Лише в режимі shadow (пробний прогін без публікації) слайди не малюються — превʼю показує їх текстом. Це нормально.

## Приклад
```json
{"format":"carousel","title":"Сирники: 4 кроки","origin":"library","library_ref":"data://recipes/42",
 "slides":[
   {"title":"Сирники без розчарувань","text":"Чотири кроки, щоб не розпливалися на пательні.","image":"https://…/syrnyky.jpg"},
   {"title":"Крок 1. Сир","text":"Беріть сухий сир 9%. Вологий — віджміть через марлю."},
   {"title":"Крок 2. Тісто","text":"На 500 г сиру — 1 яйце і 3 ложки борошна. Більше борошна — гумові сирники."},
   {"title":"Крок 3. Смаження","text":"Середній вогонь, по 3 хвилини з кожного боку, кришка не потрібна."}],
 "body":[{"type":"lead","text":"Сирники, які тримають форму"},{"type":"p","text":"Збережіть, щоб не шукати в неділю зранку."}],
 "hashtags":["рецепти"]}
```

## Погано
- 10 слайдів по 400 символів: на картинці це дрібний шрифт, ніхто не дочитає.
- Карусель з однієї думки, розтягнутої на 5 слайдів.
