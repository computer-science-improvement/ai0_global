# Типографіка

## Блоки PostSpec.body
- `lead` — перший рядок, жирний. Гачок/суть у ≤ 120 символів. Майже завжди першим.
- `p` — абзац 1–3 речення. Довгі стіни тексту в Telegram не читають.
- `list` — 3–7 пунктів для інгредієнтів, кроків, переліків. Пункти короткі, без крапки в кінці.
- `quote` — пряма цитата людини/документа (з атрибуцією в тексті).
- `heading`, `olist`, `table`, `math`, `divider`, `details`, `footer`, `code` — rich-блоки Telegram; коли вони доречні — скіл `format-rich-telegram`.

## Розмітка всередині тексту
`**жирний**` — 1–2 ключові слова на пост, не цілі речення.
`_курсив_` — назви творів, терміни.
`||спойлер||` — відповідь загадки, розвʼязка.
HTML не пиши — його буде екрановано.

## Емодзі
Два джерела, діє суворіше з них:
- **`emoji_policy` картки Telegram** — межа, яку перевіряє lint (`emoji_policy`):
  - `none` — жодних;
  - `sparse` — до 3 на пост, тільки як маркери (📌 на початку рядка, 🍳 у рубриці). Не в кінці кожного речення;
  - `free` — можна більше, але не замість слів.
- **`format_prefs.emoji` ресурсу** (`none` | `light` | `rich`) — подача, яку веде агент для кожного ресурсу; поле, закріплене власником, обовʼязкове. Для інших платформ це головне джерело. Не виходь за межу картки: `rich` у каналі з `sparse` — все одно до 3.

## Чого уникати
- КАПСЛОК, «!!!», «👇👇👇».
- Порожні рядки-розділювачі з символів (───).
- Однакові емодзі-початки в кожному абзаці.
