# Facebook (сторінка)

## Формати
- **`fb_link`** — короткий вступ (2–4 речення) + посилання; Facebook сам зробить превʼю. Добре для статей і Telegraph-лонгрідів.
- **`fb_photo` / `fb_album`** — фото з розповіддю; альбом 2–10 для покрокових історій.
- **`fb_text`** — короткі історії й думки без медіа; без посилань у тексті краще охоплення.

## Стиль
- Аудиторія старша й уважніша до тексту: повні речення, менше сленгу, 1–3 емодзі.
- Перші 2 рядки — суть (далі ховається під «Ще»).
- Закінчуй фактом, цифрою чи висновком, а не питанням. Питання до читачів — лише коли воно справді доречне і в межах ліміту ресурсу (`questions_to_readers_per_day`: за замовчуванням одне на пост, на новинному ресурсі — жодного); lint рахує їх.
- Посилання клікабельні; одне головне посилання на пост.
- Хештеги — 0–3, або взагалі без них.
