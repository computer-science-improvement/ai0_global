# YouTube Shorts (019b)

- Формат `yt_short` з'явиться разом із відеоконвеєром (shorts-studio → 016 → 019b). Зараз не плануй YouTube-слоти.
- Назва — до 90 символів, з ключовою фразою на початку; опис — 2–3 речення + 2–3 хештеги (#Shorts додає код).
- Поки API-проєкт не пройшов перевірку Google, завантаження приватні; квота API обмежує кількість відео на день.
