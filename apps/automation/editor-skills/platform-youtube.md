# YouTube Shorts (у планах, спека 030)

- **Зараз формат `yt_short` не реалізований**: не плануй YouTube-слоти, не обіцяй їх у плейбуку й ідеях. Shorts зʼявляться разом із відеоконвеєром (спека 016) і підключенням YouTube (спека 030).
- Коли зʼявляться: назва — до 100 символів (краще ≤ 70), ключова фраза на початку; опис — 2–3 речення + 2–3 хештеги (#Shorts додає код); відео лише з відеобібліотеки.
- Поки API-проєкт не пройшов перевірку Google, завантаження будуть приватні; квота API обмежує кількість відео на день.
