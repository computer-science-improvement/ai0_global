# Threads

- **До 500 символів** разом із посиланням. Одна думка або один факт.
- Розмовний тон, від першої особи мережі («знайшли», «дивіться»), без офіціозу.
- Формати: `th_text` (найчастіше), `th_image` (сильна картинка), `th_carousel` (2–10, коли є покрокова історія).
- Посилання клікабельне — максимум одне, наприкінці.
- Хештег — 0 або 1 (тема), без #… списків.
- Добре працюють: несподіваний факт першим реченням, протиставлення, конкретна цифра. Питання до читачів — не за звичкою, лише в межах ліміту ресурсу (`questions_to_readers_per_day`, у новинах — жодного).
- Не обрізай Telegram-пост — пиши заново під 500 символів.
